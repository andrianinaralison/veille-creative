Labels anglais dans la topbar

Findings

P3
Champ contextuel — apparition au bon moment
Le champ YouTube handle n'apparaît que lorsque "YouTube" est sélectionné. Zéro friction, UX progressive.
P4
Chip de confirmation immédiate
Le chip "YouTube @tobifilmsofficial" confirme la saisie avant de soumettre — feedback positif ancré dans la même zone.
C7
Tabs : form réinitialisé au switch
Si l'admin passe à l'onglet "Liens manuels" alors qu'un formulaire est en cours de saisie, les données sont perdues au retour.
Fix : remonter l'état form dans CurationPage. Effort S.
M3
Pas de feedback si AJOUTER échoue
Si le serveur renvoie 500, le bouton "Ajouter" reprend son état normal sans message d'erreur visible.
Fix : afficher l'erreur sous le bouton (pattern LinksTab). Effort S.

Findings

P5
Titre contextuel "Scan — Nom créateur"
Le titre change dynamiquement selon la session en cours. L'admin sait immédiatement quel créateur est en train d'être scanné.
P6
Compteurs éditoriaux — chiffre géant + label mono
TROUVÉES / SAUVEGARDÉES en 52px serif. Très lisible, donne le sentiment d'un outil professionnel et contrôlé.
M2
Polling à 1s (devrait être 2s)
setInterval(poll, 1000) génère ~60 requêtes pour un scan de 60 refs. Charge réseau inutile, doc dit 2s.
Fix : passer à 2000ms. Effort XS.
M3
Aucun feedback si startScan() échoue
catch(err) { console.error; setScanning(null) } — l'admin voit le bouton "Scrapper" se dégriser sans explication.
Fix : stocker l'erreur dans state et l'afficher. Effort XS.
scan terminé → transition automatique

Findings

P7
"8 À TRIER" — signal de complétude fort
Le chiffre en serif 72px est l'élément dominant de l'écran. L'admin comprend instantanément l'ampleur du lot.
B2
Navigation = perte de session (CONFIRMÉ LIVE)
Cliquer "← Retour" ou aller sur /références remet phase=idle. Les refs restantes en TRIAGE sont invisibles — impossibles à retrouver sans rechargement manuel.
Fix : restaurer la session au chargement (GET sessions?status=RUNNING). Ticket #180-29.
L1
Compteur scrolle hors viewport pendant le tri (LIVE)
Dès le 1er scroll vers les cards, le "8 À TRIER" disparaît. Pendant le tri, l'admin ne sait plus combien il en reste sans remonter.
Fix : rendre le compteur sticky. Effort XS.
B3
NL search échoue silencieusement (CONFIRMÉ LIVE)
console: {"error":"Erreur serveur"} — le grid reste inchangé, 0 message visible. L'admin croit que la recherche est vide.
Fix : (1) implémenter l'endpoint. (2) afficher l'erreur. Ticket #180-31.
L2
FILTRER sans état de chargement (LIVE)
Le bouton ne montre pas "..." pendant l'appel. L'admin peut croire que son clic n'a pas été pris en compte.
Fix : setFiltering(true) → "…" pendant l'appel async. Effort XS.
C2
Bulk buttons — différentiel visuel
"Tout garder" et "Tout rejeter" ont des traitements différents, mais vérifier que le différentiel est suffisamment lisible sur écran sombre.
C6
Placeholder NL search ambigu
Ne précise pas que la recherche est limitée au lot en cours, pas à toute la bibliothèque.
Fix : "Filtrer ce lot — ex: …". Effort XS.
P8
Bulk actions — "Tout garder (N)"
Le compteur dans le label du bouton est en temps réel — il reflète exactement les refs restantes. Pattern intuitif pour un lot homogène.

Findings

P9
Transition instantanée au clic
GARDER retire la card immédiatement sans rechargement. La grille se repaquète seule. Le compteur décrémente en temps réel. Flow opérationnel.
P10
"Set Live" s'allume dès la 1re décision
L'admin sait qu'il a des modifications à publier — le bouton topbar devient actif (inverted) après le 1er GARDER.
C4
Boutons sans aria-label contextualisé
Lecteur d'écran : "Garder, bouton" — sans savoir de quelle vidéo. WCAG SC 2.4.6.
Fix : aria-label="Garder — {titre}". Effort XS.
C3
TagEditor — pas de fermeture sur Escape
Si le dropdown de tags est ouvert, Escape ne le ferme pas. Utilisateurs clavier bloqués.
Fix : addEventListener('keydown', e => e.key==='Escape' && setOpen(false)). Effort XS.
C5
MonitoringView — pas de région ARIA live
Les compteurs TROUVÉES/SAUVEGARDÉES changent chaque seconde mais ne sont pas aria-live="polite".
Fix : wrapper les compteurs dans aria-live="polite" aria-atomic="true". Effort XS.

Findings

B1
TagEditor ALLOWED_TAGS ≠ taxonomie Claude
32 tags codés en dur (Sony-FX3, slow-motion, mariage…) vs. 18 axes / ~130 slugs utilisés par Claude à l'enrichissement. L'admin ne peut pas corriger les tags Claude via l'éditeur.
Fix : importer config/taxonomy.js dans TagEditor (ticket T-05). Effort M.
P11
Contexte éditorial Claude — qualité remarquable
L'enrichissement Claude produit un contexte éditorial précis, en français, stylé. C'est la valeur différenciante du produit — visible et lisible dans cette interface.
M1
window.confirm() pour la suppression
Dialog natif gris système sur fond dark cinema. Casse la charte et bloque le thread UI.
Fix : confirmer inline sur la ligne ("Confirmer ?" + 2 boutons). Effort S.
M4
Ligne dirty non visuellement proéminente
Modifier tags + section + statut et naviguer ailleurs = perte silencieuse. Le bouton "Enregistrer" change d'état mais est invisible dans une table dense.
Fix : teinte de fond sur la tr quand isDirtyLocal=true. Effort XS.
M5
ResultsTable sans pagination
La session entière est chargée en mémoire. 200+ refs → ~600 composants React, scroll laggy, FID élevé.
Fix : pagination 50/page côté serveur. Effort M.
