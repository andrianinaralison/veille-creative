## Ce que le challenge a changé

Le ticket initial était un **fix mécanique** (« remplacer fetch par apiFetch »). Le challenge l'a requalifié en **fix de la cause racine** :

1. **Reframing produit (Sophie)** — le bug n'est pas « mauvais client HTTP », c'est « Léa voit une bibliothèque vide sans explication ». Tout futur incident API redonnerait le même symptôme si on ne traite que l'auth.
2. **Cause racine nommée (Alex)** — `.catch(() => ({ references: [] }))` : une erreur rendue indistinguable d'un état vide légitime. C'est ce pattern qui a aveuglé le smoke test, pas l'absence de header.
3. **Le bon fix existe déjà (Thomas)** — `api.references.list()` / `.sections()` sont écrits dans `lib/api.js` et jamais branchés. Pas de nouveau code à inventer.
4. **Design sans wireframe (Marie)** — état erreur ≠ état vide, pattern à copier de `Dashboard.jsx`.
